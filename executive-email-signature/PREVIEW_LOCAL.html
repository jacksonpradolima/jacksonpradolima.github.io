    Install in Gmail

    1. Wait until all five hosted images pass the check above. Open Gmail → Settings → See all settings → General → Signature.
    2. Create Prado Lima | Executive. Copy the full signature and paste it into the editor using Ctrl+V.
    3. Create Prado Lima | Reply. Copy and paste the reply signature.
    4. Under Signature defaults, set For new emails: Prado Lima | Executive and For replies/forwards: Prado Lima | Reply.
    5. Click Save Changes at the bottom. Reopen settings to confirm the signatures persisted.
    6. Compose a message and use the Insert signature (pen) menu to switch signatures for that email. Send a test to another account and inspect desktop and mobile.

    Live Gmail insertion, persistence, and received-message rendering require a manual test. Browser previews alone do not verify them.
